# Locally hosted catalog photography

The capsule and recipe photographs in these folders are local copies of images served by Nespresso product and recipe pages. The original recipe links remain on each recipe card; capsule cards link to the official Nespresso Canada catalog.

Image copyrights and trademarks belong to Nespresso and their respective owners. This hobby project is not affiliated with Nespresso.

Images sourced from the Nespresso Canada media CDN and recipe API to keep the public GitHub Pages site from depending on third-party image hosting. The recipe-book photographs in `../recipe-book/` were extracted from the Nespresso recipe book already included in the project.
