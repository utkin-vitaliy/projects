# Capsule Shelf

Личный учёт капсул Nespresso Original: остатки, любимые сорта, пороги пополнения и заметки о вкусе.

## Запуск

```bash
npm install
npm run dev
```

Одна команда запускает интерфейс Vite и локальный Node API. Открой адрес Vite, который появится в терминале. API слушает только `127.0.0.1:3001`, а браузер обращается к нему через Vite proxy.

## Файл данных и миграция

Количество, отметки «избранное», пороги и заметки автоматически сохраняются в `data/inventory.json` относительно папки проекта. Это обычный читаемый JSON-файл, который можно скопировать для резервной копии. Он исключён из Git, чтобы личные данные случайно не попали в коммит.

При первом запуске приложение один раз перенесёт данные из прежнего ключа `localStorage` (`capsule-shelf:inventory:v1`), если JSON-файла ещё нет. Старый ключ удаляется только после успешной записи файла. Если JSON-файл уже существует, он является источником данных; localStorage не читается.

При недоступном API приложение покажет уведомление и останется доступным до закрытия страницы, но изменения не будут сохранены. Повреждённый JSON не перезаписывается автоматически: восстанови файл из резервной копии или вручную исправь его, затем перезапусти приложение. Запись выполняется через временный файл и атомарное переименование.

Пользовательские данные остаются на этом компьютере. Аккаунта и облачной синхронизации нет.

## Каталог и изображения

Каталог — вручную поддерживаемый снимок из 40 индивидуальных сортов Nespresso Original Canada, проверенный 3 ноября 2026 года. В него входят лимитированные серии, итальянские эспрессо, декофеинизированные сорта, региональные линейки, происхождения, ароматизированный кофе и классика. Повторения сортов между разделами сайта объединены; наборы, ассорти, подарочные комплекты, адвент-календари, машины, аксессуары и сиропы исключены. Актуальность ассортимента нужно обновлять вручную; приложение не сканирует сайт.

Источник и ссылки на товары: [каталог Nespresso Canada Original](https://www.nespresso.com/ca/en/order/capsules/original). Категории в приложении позволяют сузить каталог и работают вместе с фильтрами «Избранное» и «Пора пополнить».

Фотографии загружаются браузером напрямую с `nespresso.com`; заметки и остатки сайту не передаются. Если фотография недоступна, карточка показывает заглушку. Перед публикацией приложения нужно отдельно проверить разрешения на использование фотографий и товарных знаков.

Этот личный проект не является официальным приложением Nespresso и не связан с компанией Nestlé Nespresso S.A.
